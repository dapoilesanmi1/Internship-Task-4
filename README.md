# Kanban Lite — Interactive Task Board
Link live at: https://dapoilesanmi1.github.io/Internship-Task-4/

A responsive task board built with plain HTML5, CSS3 and vanilla JavaScript 

## Features
- Add tasks with title, description, category and priority
- Three columns: To Do, In Progress, Completed
- Move tasks with the dropdown on each card **or** by drag and drop
- Delete tasks
- Tasks persist in `localStorage`
- Priority colours: High = coral, Medium = amber, Low = green
- Search by title and filter by category
- Dark mode toggle (remembers your choice, follows your system setting on first visit)
- Live counter of active vs completed tasks
- Responsive: one column on phones, three on tablet and desktop

## Files
- `index.html` — structure
- `style.css` — styling, with light/dark theme variables
- `script.js` — state, rendering, storage, drag and drop, theme
